# Waraq bundled data

- **CAMeL Morph MSA 1.0**: CAMeL Lab, New York University Abu Dhabi. Data licensed CC BY 4.0, https://creativecommons.org/licenses/by/4.0/. Source: https://github.com/CAMeL-Lab/camel_morph/tree/main/official_releases/lrec-coling2024_release. Waraq compiles a subset of analysis fields into sharded JSON; the analysis algorithm is adapted from CAMeL Tools 1.6.0 (MIT, included separately). Preserve attribution. Candidate readings are not contextual disambiguation.
- **Kaikki / English Wiktionary Arabic entries**: https://kaikki.org/dictionary/Arabic/, derived from English Wiktionary contributors under CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/. Each entry retains its Wiktionary URL. Waraq filters fields and creates search indexes; share adapted text under the same license.
- **Lane's Arabic-English Lexicon database**: https://github.com/laneslexicon/LexiconDatabase, GPL-3.0 distribution. Credits the Perseus digitization of Edward William Lane's lexicon. Waraq preserves the extracted wording and source sense markers, retains italic gloss emphasis in the reading layout, and compiles entries into JSON and SQLite. The modified conversion source is in scripts/prepare_data.py and scripts/package_playgrounds.py. The archive includes these scripts and the upstream GPL notice in Licenses. Source XML is available from the repository's lexicon.sqlite.zip.
- **Hans Wehr**: no dictionary text, scans, or OCR database is bundled. The PDF reference viewer only opens a file the user imports.
- **Release source material**: the [v0.2.4 release](https://github.com/SlyZ1228/waraq/releases/tag/v0.2.4) includes an optional `Waraq-Lane-Source.zip` with the upstream Lane database archive (including its XML entries), notices, and conversion scripts. Application and conversion source for this build is available at [the matching tag](https://github.com/SlyZ1228/waraq/tree/v0.2.4). The source archive is not needed to run the reader.
- **Fonts and application libraries**: Noto Naskh Arabic (SIL OFL), Inter (SIL OFL), React (MIT), EPUB.js (BSD-2-Clause), JSZip (MIT option), idb (ISC), Lucide (ISC). See the included upstream notices. No external JavaScript or font service is required.
